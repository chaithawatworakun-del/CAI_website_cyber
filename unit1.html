UNIT 01 • พื้นฐานระบบเครือข่าย

รู้จักเครือข่ายคอมพิวเตอร์

Introduction to Computer Networks and Topologies

เวลาเรียน: 2 ชั่วโมง วิดีโอบทเรียน 6 หมวดเนื้อหาหลัก สรุปสาระสำคัญ

จุดประสงค์การเรียนรู้

เมื่อศึกษาหน่วยนี้แล้ว ผู้เรียนจะมีความรู้ความสามารถดังนี้

1. อธิบายความหมาย ความสำคัญ และประโยชน์ของระบบเครือข่ายคอมพิวเตอร์ได้อย่างถูกต้อง
2. จำแนกประเภทของเครือข่ายคอมพิวเตอร์ตามขนาดพื้นที่ (PAN, LAN, MAN, WAN) ได้
3. วิเคราะห์โครงสร้างการเชื่อมต่อเครือข่าย (Topology) ในรูปแบบต่างๆ พร้อมบอกข้อดี-ข้อจำกัดได้
4. เปรียบเทียบสถาปัตยกรรมแบบ Client-Server และ Peer-to-Peer ได้อย่างชัดเจน

วิดีโอเสริมการเรียนรู้: เครือข่ายคอมพิวเตอร์คืออะไร?

รับชมคลิปสรุปแนวคิดพื้นฐานระบบเครือข่ายคอมพิวเตอร์เพื่อความเข้าใจที่ชัดเจนยิ่งขึ้น

บทเรียนมัลติมีเดีย
หากมีข้อจำกัดด้านเบราว์เซอร์หรือเครื่องขัดข้อง สามารถเปิดดูผ่าน YouTube ได้โดยตรง: เปิดดูบน YouTube

ประเด็นสำคัญในคลิปวิดีโอ:

  • ความหมายและประโยชน์ของระบบ Computer Network
  • การทำงานร่วมกันของอุปกรณ์ส่ง-รับข้อมูล
  • การเชื่อมต่อตัวกลางแบบมีสายและไร้สาย
คำแนะนำสำหรับผู้เรียน

แนะนำให้รับชมคลิปประกอบการอ่านเนื้อหาด้านล่าง เพื่อช่วยให้เห็นภาพรวมขององค์ประกอบเครือข่ายได้อย่างเป็นรูปธรรม

1.1

ความหมาย วิวัฒนาการ และบทบาทของเครือข่ายคอมพิวเตอร์

เครือข่ายคอมพิวเตอร์ (Computer Network) คือ ระบบการเชื่อมโยงคอมพิวเตอร์ตั้งแต่ 2 เครื่องขึ้นไป รวมถึงอุปกรณ์สื่อสารอิเล็กทรอนิกส์ เช่น สมาร์ตโฟน เซิร์ฟเวอร์ พรินเตอร์ และเซนเซอร์ IoT เข้าด้วยกันผ่านตัวกลางการสื่อสาร (ทั้งแบบใช้สายและไร้สาย) เพื่อให้สามารถสื่อสาร แลกเปลี่ยนข้อมูล และแบ่งปันการใช้ทรัพยากรร่วมกันได้อย่างมีประสิทธิภาพสูงสุด

ในอดีต คอมพิวเตอร์ทำงานแบบเอกเทศ (Standalone) การส่งผ่านข้อมูลต้องอาศัยสื่อบันทึกทางกายภาพ เช่น แผ่นฟลอปปีดิสก์ (Floppy Disk) จนกระทั่งปี ค.ศ. 1969 กระทรวงกลาโหมสหรัฐฯ ได้ริเริ่มโครงการ ARPANET (Advanced Research Projects Agency Network) ซึ่งเป็นจุดกำเนิดของอินเทอร์เน็ต และพัฒนาเรื่อยมาจนกลายเป็นโครงสร้างพื้นฐานดิจิทัลที่ขับเคลื่อนโลกในปัจจุบัน

Interconnected World

การเชื่อมต่อแบบไร้รอยต่อระหว่าง Client, Server และ Cloud ทั่วโลก

Devices Storage Cloud

ประโยชน์หลัก 5 ประการของระบบเครือข่ายคอมพิวเตอร์:

1. การใช้ทรัพยากรร่วมกัน (Resource Sharing)

ใช้อุปกรณ์ฮาร์ดแวร์ราคาสูงร่วมกัน เช่น Network Printer, High-Speed Scanner, อุปกรณ์จัดเก็บข้อมูลกลาง (NAS / SAN)

2. การรวมศูนย์ข้อมูล (Data Centralization)

จัดเก็บฐานข้อมูลและเอกสารไว้ที่ศูนย์กลาง ทำให้ทุกคนเข้าถึงข้อมูลที่เป็นปัจจุบันเดียวกัน สำรองข้อมูล (Backup) ง่ายและปลอดภัย

3. การสื่อสารที่รวดเร็ว (Fast Communication)

ส่งต่ออีเมล แชต วิดีโอคอนเฟอเรนซ์ และการทำงานร่วมกันแบบเรียลไทม์ (Collaborative Working) ข้ามสถานที่ได้ทันที

4. การประหยัดค่าใช้จ่าย (Cost Reduction)

ลดการซื้ออุปกรณ์ซ้ำซ้อน ลดการใช้กระดาษ และสามารถใช้งาน License ซอฟต์แวร์ระดับเครือข่ายได้อย่างคุ้มค่า

5. ความน่าเชื่อถือและการสำรองระบบ (High Reliability & Redundancy)

หากเครื่องลูกข่ายหรือเส้นทางสายส่งเส้นใดชำรุด ระบบยังคงสามารถทำงานต่อไปได้ผ่านเส้นทางสำรอง (Failover & Redundancy)

1.2

องค์ประกอบพื้นฐาน 5 ประการของการสื่อสารข้อมูล (Data Communication Elements)

การส่งผ่านข้อมูลในระบบเครือข่ายจะเกิดขึ้นได้อย่างสมบูรณ์ ต้องประกอบไปด้วย 5 องค์ประกอบหลักตามแบบจำลองมาตรฐาน ดังนี้:

1. ผู้ส่ง

Sender / Source

อุปกรณ์ต้นทางที่สร้างและส่งข่าวสาร เช่น PC, โทรศัพท์, กล้อง CCTV

2. ข้อมูลข่าวสาร

Message / Data

สารสนเทศที่ต้องการส่ง เช่น ข้อความ, รูปภาพ, เสียง, วิดีโอสตรีมมิ่ง

3. สื่อกลาง

Transmission Medium

ช่องทางส่งสัญญาณทั้งแบบมีสาย (UTP, Fiber) และไร้สาย (Wi-Fi, 5G)

4. ผู้รับ

Receiver / Sink

อุปกรณ์ปลายทางที่รับข่าวสาร เช่น เซิร์ฟเวอร์, มือถือ, พรินเตอร์

5. โพรโทคอล

Protocol

กฎระเบียบและข้อตกลงในการสื่อสาร เช่น TCP/IP, HTTP, Wi-Fi 802.11

1.3

ทิศทางการส่งสัญญาณข้อมูล (Data Transmission Modes)

ทิศทางเดียว

Simplex Mode

การส่งข้อมูลแบบทิศทางเดียว

ผู้ส่งทำหน้าที่ส่งข้อมูลได้เพียงฝ่ายเดียว และผู้รับทำหน้าที่รับข้อมูลได้เพียงฝ่ายเดียว ไม่สามารถส่งย้อนกลับได้

ตัวอย่าง: คีย์บอร์ดส่งไปยังคอมพิวเตอร์, การออกอากาศวิทยุ FM/AM, สัญญาณโทรทัศน์
สองทิศทางสลับกัน

Half-Duplex Mode

การส่งข้อมูลสองทิศทางสลับกัน

ทั้งสองฝ่ายสามารถเป็นได้ทั้งผู้ส่งและผู้รับ แต่ไม่สามารถส่งพร้อมกันในเวลาเดียวกันได้ ต้องผลัดกันส่งทีละฝ่าย

ตัวอย่าง: วิทยุสื่อสาร วอล์คกี้-ทอล์คกี้ (Walkie-Talkie), ฮับ (Hub ในระบบแลนเดิม)
สองทิศทางพร้อมกัน

Full-Duplex Mode

การส่งข้อมูลสองทิศทางพร้อมกัน

ทั้งสองฝ่ายสามารถรับและส่งข้อมูลได้พร้อมๆ กันในเวลาเดียวกัน ทำให้การสื่อสารมีประสิทธิภาพสูงสุด

ตัวอย่าง: การโทรศัพท์มือถือ, ระบบเครือข่ายแลนสมัยใหม่ที่ใช้สวิตช์ (Switch Full-Duplex)
1.4

สถาปัตยกรรมระบบเครือข่าย (Network Architecture)

1. แบบแม่ข่าย-ลูกข่าย (Client-Server Architecture)

สถาปัตยกรรมมาตรฐานสำหรับองค์กร

มีการแบ่งหน้าที่ชัดเจน โดยมีคอมพิวเตอร์แม่ข่าย (Server) ประสิทธิภาพสูงทำหน้าที่ให้บริการ เช่น Web Server, File Server, Database Server และเครื่องลูกข่าย (Client) ส่งคำร้องขอ (Request) เข้ามาใช้งาน

ข้อดี: การควบคุมความปลอดภัยสูง รวมศูนย์จัดการ (Centralized), สำรองข้อมูลง่าย, รองรับผู้ใช้จำนวนมาก
ข้อจำกัด: ค่าใช้จ่ายเครื่องเซิร์ฟเวอร์สูง ต้องมีผู้ดูแลระบบเฉพาะ (System Admin) หากแม่ข่ายล่มระบบจะหยุดชะงัก

2. แบบเท่าเทียมกัน (Peer-to-Peer / P2P Architecture)

สถาปัตยกรรมแบบกระจายศูนย์

ทุกเครื่องในเครือข่ายมีสิทธิและหน้าที่เท่าเทียมกัน สามารถทำหน้าที่เป็นทั้งผู้ให้บริการ (Server) และผู้ขอใช้บริการ (Client) ในเวลาเดียวกัน นิยมใช้ในกลุ่มงานขนาดเล็ก (2-10 เครื่อง) หรือเครือข่าย BitTorrent / Blockchain

ข้อดี: ติดตั้งง่าย ต้นทุนต่ำ ไม่ต้องซื้อเซิร์ฟเวอร์ราคาแพง หากเครื่องใดดับ เครื่องอื่นยังใช้งานได้
ข้อจำกัด: การรักษาความปลอดภัยต่ำ ไม่มีการรวมศูนย์ข้อมูล ประสิทธิภาพลดลงเมื่อมีผู้ใช้จำนวนมาก
1.5

การจำแนกประเภทเครือข่ายตามระยะทางภูมิศาสตร์ (Network Categories by Scope)

ระยะใกล้มาก (1-10 m)

PAN

Personal Area Network

เครือข่ายส่วนบุคคล เช่น เชื่อมต่อสมาร์ตโฟนกับหูฟังไร้สาย Bluetooth, Apple AirDrop, Smartwatch, หรือการแชร์ Personal Hotspot

ระดับอาคาร (100 m - 1 km)

LAN

Local Area Network

เครือข่ายท้องถิ่นภายในห้องปฏิบัติการ อาคารเรียน สำนักงาน หรือบ้านพักอาศัย ความเร็วสูง (1 Gbps - 10 Gbps) เชื่อมต่อด้วยสาย UTP หรือ Wi-Fi

ระดับเมือง (10 - 50 km)

MAN

Metropolitan Area Network

เครือข่ายระดับเมือง เช่น ระบบกล้องวงจรปิด CCTV ทั่วเขตเทศบาล เครือข่ายเคเบิลทีวี หรือเครือข่ายเชื่อมโยงสาขาธนาคารภายในจังหวัดเดียว

ระดับโลก (100 - 10,000+ km)

WAN

Wide Area Network

เครือข่ายบริเวณกว้างระดับประเทศและทั่วโลก เช่น อินเทอร์เน็ต (Internet) โดยใช้เคเบิลใต้น้ำข้ามทวีป (Submarine Cable) และดาวเทียม

ประเภทเครือข่ายเฉพาะทางเพิ่มเติมที่ควรรู้จัก:

CAN (Campus Area Network): เครือข่ายเชื่อมโยงระหว่างหลายอาคารภายในวิทยาเขตมหาวิทยาลัยหรือศูนย์ราชการ
SAN (Storage Area Network): เครือข่ายความเร็วสูงพิเศษเฉพาะสำหรับเชื่อมโยงเซิร์ฟเวอร์กับสตอเรจจัดเก็บข้อมูล
VPN (Virtual Private Network): เครือข่ายเสมือนส่วนบุคคลที่เข้ารหัสข้อมูลผ่านอินเทอร์เน็ตสาธารณะ
1.6

โครงสร้างการเชื่อมต่อเครือข่ายเชิงลึก (Network Topologies)

โทโพโลยี (Topology) หมายถึง รูปแบบการจัดวางและเชื่อมต่อทางกายภาพ (Physical) และทางตรรกะ (Logical) ของโหนดต่างๆ ในเครือข่าย แต่ละรูปแบบมีจุดเด่นและข้อจำกัดที่แตกต่างกัน:

รูปแบบ Topology ลักษณะการทำงาน ข้อดี (Pros) ข้อจำกัด (Cons) การนำไปใช้จริง
Star (ดาว) ทุกโหนดเชื่อมต่อเข้าอุปกรณ์ศูนย์กลาง (Switch) แบบจุดต่อจุด สายเส้นใดขาด โหนดอื่นทำงานต่อได้ ตรวจสอบปัญหาง่าย ขยายระบบสะดวก ถ้า Switch ศูนย์กลางเสีย ระบบทั้งหมดจะล่ม (Single Point of Failure) นิยมใช้มากที่สุดในปัจจุบัน (ห้องเรียน สำนักงาน บ้าน)
Bus (บัส) ใช้สายเคเบิลหลักเส้นเดียว (Backbone) มีตัวปิดสัญญาณ (Terminator) หัวท้าย ใช้สายสัญญาณน้อย ติดตั้งง่าย ต้นทุนต่ำที่สุด ถ้าสายหลักขาด ทั้งระบบจะล่ม ตรวจหาจุดเสียยาก เกิด Collision บ่อย เครือข่ายในอดีต (Coaxial 10Base2) หรือเซนเซอร์ในโรงงานอุตสาหกรรม
Ring (วงแหวน) เชื่อมต่อเรียงกันเป็นวงกลม ส่งข้อมูลทิศทางเดียวโดยใช้ Token ไม่มีปัญหาข้อมูลชนกัน ทุกเครื่องมีสิทธิส่งเท่าเทียมกัน ถ้าโหนดหรือสายจุดใดจุดหนึ่งขาด ระบบทั้งวงแหวนจะไม่สามารถส่งข้อมูลได้ เครือข่าย Token Ring ในอดีต และ FDDI Fiber Optic Backbone
Mesh (ตาข่าย) ทุกโหนดเชื่อมต่อถึงกันโดยตรงแบบ Point-to-Point (Full Mesh: n(n-1)/2 เส้น) ความเสถียรและความปลอดภัยสูงสุด มีเส้นทางสำรองเสมอ (Fault Tolerant) เปลืองสายสัญญาณและพอร์ตเชื่อมต่อมากที่สุด ค่าใช้จ่ายสูงมาก Core Router ของผู้ให้บริการอินเทอร์เน็ต (ISP) และ Data Center
Tree / Hybrid (ต้นไม้/ผสม) รวม Star หลายวงเข้าด้วยกันเป็นลำดับชั้น (Hierarchical) หรือผสมผสาน รองรับการขยายเครือข่ายขนาดใหญ่ จัดกลุ่มแผนกได้เป็นระเบียบ หาก Switch ระดับบน (Core Switch) มีปัญหาจะกระทบวงย่อยทั้งหมด เครือข่ายระดับองค์กรขนาดใหญ่ โรงเรียน มหาวิทยาลัย

ทบทวนความรู้สำคัญก่อนก้าวสู่บทเรียนถัดไป

นิยามเครือข่าย: การเชื่อมต่อคอมพิวเตอร์และอุปกรณ์เพื่อแบ่งปันทรัพยากร (Resource Sharing) รวมศูนย์ข้อมูล และสื่อสารรวดเร็ว
5 องค์ประกอบ: ผู้ส่ง (Sender), ข้อมูล (Message), สื่อกลาง (Medium), ผู้รับ (Receiver), โพรโทคอล (Protocol)
ทิศทางการส่งข้อมูล: Simplex (ทิศทางเดียว), Half-Duplex (สลับกัน), Full-Duplex (สองทิศทางพร้อมกัน - นิยมสุด)
ลำดับขนาดเครือข่าย: PAN (ส่วนตัว) < LAN (ท้องถิ่น/อาคาร) < MAN (เมือง) < WAN (ระดับโลก/อินเทอร์เน็ต)
Star Topology: นิยมใช้มากที่สุดในปัจจุบัน เพราะจัดการง่ายและหากสายขาด 1 จุดจะไม่กระทบเครื่องอื่น
Client-Server vs P2P: Client-Server ปลอดภัยและเหมาะกับองค์กร ส่วน P2P ประหยัดและเหมาะกับกลุ่มงานขนาดเล็ก
