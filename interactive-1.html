ENTERPRISE TOPOLOGY LAB

นำเมาส์ไปชี้หรือแตะค้างที่จุดอุปกรณ์รอบๆ ผัง

1. Router
Layer 3: Network ONLINE
1. Router (เราเตอร์เชื่อมต่อเครือข่าย)
ประเภทอุปกรณ์: Dual-Band Gigabit Wi-Fi Router
โพรโทคอล & ฟังก์ชัน: IP Routing, NAT, DHCP, DNS

เชื่อมต่อเครือข่ายต่าง Subnet หรือเชื่อมวง LAN ภายในออกสู่อินเทอร์เน็ต WAN โดยอ่าน Logical IP Address บน Routing Table เพื่อเลือกเส้นทางส่งข้อมูล (Packet) ที่เร็วและมีประสิทธิภาพที่สุด

ประเด็นสำคัญ: Router ทำงานที่ Layer 3 ใช้ Logical IP Address ในการนำทาง และช่วยแบ่งแยก Broadcast Domain ออกจากกัน
2. Firewall
Layer 4 - 7: Security ACTIVE IPS
2. Firewall (ไฟร์วอลล์ความปลอดภัย)
ฮาร์ดแวร์สเปก: FortiGate NGFW / Multi-Gigabit
ระบบความปลอดภัย: Deep Packet, SSL, IPS/IDS, VPN

ปราการด่านแรกป้องกันภัยคุกคาม กรองทราฟฟิกข้อมูลเข้า-ออกตามนโยบายความปลอดภัย (Security Rules) ดักจับมัลแวร์ ป้องกันการโจมตี DDoS และตรวจจับการแฮกเจาะระบบแบบ Real-time

จุดเด่น: Next-Gen Firewall (NGFW) สามารถตรวจจับและวิเคราะห์แพ็กเกจลึกถึงระดับ Layer 7 (Application Layer)
3. Switch
Layer 2: Data Link 24 PORTS UP
3. Switch (สวิตช์รวมสัญญาณ LAN)
พอร์ตเชื่อมต่อ: 24-Port Gigabit 10/100/1000 Mbps
เทคโนโลยีหลัก: MAC Address Table, Full-Duplex

อุปกรณ์รวมสายสัญญาณสำหรับคอมพิวเตอร์ในวง LAN ส่งเฟรมข้อมูลแบบ Unicast ไปยังพอร์ตปลายทางโดยจดจำ Physical MAC Address ลงในตาราง MAC Address Table

ข้อดีเหนือกว่า Hub: Switch แยก 1 Collision Domain ต่อ 1 พอร์ต ข้อมูลไม่ชนกัน 100% และรับ-ส่งข้อมูลได้พร้อมกันสองทิศทาง
4. Hub
Layer 1: Physical ⚠️ LEGACY HUB
4. Hub (ฮับรวมสัญญาณ - เทคโนโลยีเดิม)
ลักษณะการทำงาน: Multiport Repeater / 8-Port
การส่งสัญญาณ: Broadcast ทุกพอร์ต (Half-Duplex)

อุปกรณ์รวมสัญญาณรุ่นแรก ทำหน้าที่ทวนสัญญาณไฟฟ้าแล้วกระจายออกทุกพอร์ตโดยไม่มีความฉลาด ทุกอุปกรณ์แชร์แบนด์วิดท์ร่วมกัน เกิดปัญหาข้อมูลชนกัน (Collision) บ่อยครั้ง

ประเด็นสำคัญ: Hub มีเพียง 1 Collision Domain รวมกันทั้งเครื่อง ปัจจุบันยกเลิกใช้งานและถูกแทนที่ด้วย Switch ทั้งหมด
5. Access Point
Layer 1 - 2: Wireless WI-FI READY
5. Wireless Access Point (จุดกระจายสัญญาณไร้สาย)
ย่านความถี่ Wi-Fi: Dual-Band 2.4 GHz & 5 GHz
ฟังก์ชันเด่น: PoE, WPA3, Multi-SSID, Roaming

อุปกรณ์ทำหน้าที่เป็นสะพานเชื่อมระหว่างเครือข่ายมีสาย (LAN) เข้ากับสัญญาณไร้สาย (Wi-Fi) ช่วยให้สมาร์ตโฟน แล็ปท็อป และอุปกรณ์ IoT เชื่อมโยงเข้าสู่ระบบเครือข่ายได้อย่างอิสระ

เทคโนโลยีสำคัญ: รองรับ PoE (จ่ายไฟผ่านสายแลนเส้นเดียว) ติดตั้งบนฝ้าเพดานได้เรียบร้อย และมีระบบ Fast Roaming ข้ามจุดสัญญาณไม่หลุด
6. Modem (ONT)
Layer 1: Physical / WAN GPON FIBER UP
6. Fiber Modem / ONT (โมเด็มไฟเบอร์)
พอร์ตสัญญาณเข้า: GPON Fiber Optic (SC/APC)
หน้าที่หลัก: แปลงสัญญาณแสงเป็นสัญญาณดิจิทัล

อุปกรณ์โมเด็มไฟเบอร์ (Optical Network Terminal) ทำหน้าที่แปลงสัญญาณแสง (Light Pulse) ผ่านสายใยแก้วนำแสงจากผู้ให้บริการอินเทอร์เน็ต (ISP) ให้เป็นสัญญาณไฟฟ้าดิจิทัลก่อนส่งเข้า Firewall และ Router

ข้อสังเกตไฟสถานะ: ไฟ PON สีเขียวค้างหมายถึงเชื่อมต่อโครงข่าย ISP สำเร็จ หากไฟ LOS สีแดงกะพริบแสดงว่าไม่ได้รับสัญญาณแสงจากสายไฟเบอร์
