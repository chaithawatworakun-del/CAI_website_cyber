ENTERPRISE TOPOLOGY LAB

นำเมาส์ไปชี้หรือแตะค้างที่จุดอุปกรณ์รอบๆ ผัง

1. Core Router
Layer 3: Network ONLINE
1. Core Gateway Router
ฮาร์ดแวร์สเปก: Dual 10G SFP+ / 8GB RAM
โพรโทคอลที่ใช้: BGP, OSPF, IPv4/IPv6, NAT

เชื่อมต่อเครือข่ายภายใน LAN ออกสู่อินเทอร์เน็ต WAN โดยอ่าน Logical IP Address บน Routing Table เพื่อเลือกเส้นทางส่งข้อมูลที่เร็วที่สุด

ประเด็นสำคัญ: Router ทำงานที่ Layer 3 ใช้ Logical IP Address ในการส่ง Packet
2. Firewall NGFW
Layer 4 - 7: Security ACTIVE IPS
2. Next-Gen Hardware Firewall
ความเร็วการกรอง: 10 Gbps / Zero-Day IPS
เทคโนโลยี: Deep Packet, SSL, VPN

ปราการด่านแรกป้องกันภัยคุกคาม กรองทราฟฟิก ดักจับมัลแวร์ ป้องกันการโจมตี DDoS และตรวจจับการแฮกเจาะระบบแบบ Real-time

จุดเด่น: NGFW สามารถตรวจจับไวรัสที่ซ่อนลึกถึงระดับ Layer 7 (Application)
3. L3 Switch
Layer 2 - 3: Switch 48 PORTS UP
3. Layer 3 Managed Core Switch
พอร์ตเชื่อมต่อ: 48x 1G PoE+ & 4x 10G SFP+
ฟีเจอร์เด่น: VLAN 802.1Q, LACP, STP

สวิตช์จัดการโครงข่ายหลัก รองรับการแบ่ง VLAN แยกแผนกงานเพื่อความปลอดภัย และส่งเฟรมข้อมูลด้วยตาราง MAC Address Table ตรงสู่พอร์ตปลายทาง

ข้อดี: ลดปัญหา Broadcast Domain และป้องกันการชนกันของสัญญาณ 100%
4. Patch Panel
Layer 1: Physical 10Gbps CAT6A
4. Patch Panel & Structured Cabling
มาตรฐานสาย: Cat 6A 500MHz Shielded
มาตรฐานเข้าสาย: TIA/EIA-568B, RJ-45

แผงกระจายสายแลนจุดรวมการเชื่อมต่อจากทุกห้องเข้าสู่ตู้ Rack ช่วยจัดสายเป็นระเบียบ ซ่อมบำรุงและสลับพอร์ตได้สะดวกรวดเร็ว

เทคนิคช่าง: คลายเกลียวคู่สายก่อนเข้าพอร์ตไม่เกิน 1.3 ซม. เพื่อกัน Crosstalk
5. Wi-Fi 7 AP
Layer 1 - 2: Wireless 9.3 Gbps READY
5. Enterprise Wi-Fi 7 Access Point
ย่านความถี่: Tri-Band 2.4/5/6 GHz
ความปลอดภัย: WPA3, 4x4 MU-MIMO

จุดกระจายสัญญาณอินเทอร์เน็ตไร้สายสำหรับแล็ปท็อป สมาร์ตโฟน และอุปกรณ์ IoT รองรับผู้ใช้งานหนาแน่นพร้อมกันหลายร้อยเครื่องแบบไร้รอยต่อ

เทคโนโลยีเด่น: MLO (Multi-Link Operation) เชื่อมหลายย่านความถี่พร้อมกัน Latency ต่ำกว่า 5ms
6. Data Server
Layer 7: Application RAID 10 HEALTHY
6. Data Server & Backup Vault
สเปกประมวลผล: Dual Xeon, 128GB ECC RAM
โพรโทคอลบริการ: HTTPS, SFTP, NFS, SMB 3.0

ให้บริการประมวลผล จัดเก็บฐานข้อมูล และสำรองข้อมูลแบบ 3-2-1 Backup ป้องกันความเสียหายจากไวรัสเรียกค่าไถ่ Ransomware
