UNIT 02 • ฮาร์ดแวร์ระบบเครือข่าย

อุปกรณ์เครือข่ายคอมพิวเตอร์

Network Hardware Devices: Router, Switch, AP, Gateway and NIC

เวลาเรียน: 2.5 ชั่วโมง วิดีโอบทเรียน 6 หมวดอุปกรณ์หลัก สรุปสาระสำคัญ

จุดประสงค์การเรียนรู้

เมื่อศึกษาหน่วยนี้แล้ว ผู้เรียนจะมีความรู้ความสามารถดังนี้

1. ระบุหน้าที่และหลักการทำงานของอุปกรณ์เครือข่ายแต่ละประเภทได้อย่างถูกต้อง
2. อธิบายความแตกต่างระหว่าง Switch และ Hub พร้อมเปรียบเทียบเรื่อง Collision Domain ได้
3. เข้าใจการทำงานของ Router ในการค้นหาเส้นทางและการแจก IP Address (DHCP)
4. เลือกใช้อุปกรณ์เครือข่ายให้เหมาะสมกับขนาดและความต้องการขององค์กรได้

วิดีโอเสริมการเรียนรู้: อุปกรณ์เครือข่ายคอมพิวเตอร์

ทำความเข้าใจหน้าที่และบทบาทของอุปกรณ์ Network Hardware แต่ละชนิดอย่างเข้าใจง่าย

บทเรียนมัลติมีเดีย
หากมีข้อจำกัดด้านเบราว์เซอร์หรือเครื่องขัดข้อง สามารถเปิดดูผ่าน YouTube ได้โดยตรง: เปิดดูบน YouTube

ประเด็นสำคัญในคลิปวิดีโอ:

  • หน้าที่หลักของการ์ดแลน (NIC) และ Router
  • ความแตกต่างในการรับส่งข้อมูลระหว่าง Hub และ Switch
  • การกระจายสัญญาณไร้สายด้วย Access Point (AP)
คำแนะนำสำหรับผู้เรียน

เมื่อดูคลิปจบแล้ว แนะนำให้อ่านรายละเอียดทางเทคนิค เช่น 48-bit MAC Address, Collision Domain และมาตรฐาน Wi-Fi 6/7 ในหัวข้อถัดไป

2.1

การ์ดแลน (NIC) และหมายเลขประจำตัวทางกายภาพ (MAC Address)

การ์ดแลน (Network Interface Card - NIC) หรือ Network Adapter คือ แผงวงจรฮาร์ดแวร์ที่ติดตั้งอยู่ในคอมพิวเตอร์หรืออุปกรณ์ดิจิทัล ทำหน้าที่เป็นสะพานเชื่อมต่อระหว่างอุปกรณ์กับสื่อกลางส่งข้อมูล (ทั้งแบบสาย RJ-45 และแบบไร้สาย Wi-Fi) โดยแปลงข้อมูลดิจิทัลภายในเครื่องให้เป็นสัญญาณไฟฟ้า สัญญาณแสง หรือคลื่นวิทยุ

บนการ์ดแลนทุกใบจากโรงงาน จะถูกบันทึกหมายเลขประจำตัวฮาร์ดแวร์ที่ไม่ซ้ำกันในโลก เรียกว่า MAC Address (Media Access Control Address) หรือ Physical Address ขนาด 48 บิต (6 ไบต์) เขียนแสดงในรูปเลขฐานสิบหก (Hexadecimal) คั่นด้วยเครื่องหมายโคลอนหรือขีด เช่น 00:1A:2B:3C:4D:5E

48-bit MAC Address Structure

24 บิตแรก (3 ไบต์) OUI (Organizationally Unique Identifier)

รหัสระบุบริษัทผู้ผลิต เช่น Cisco, Apple, Intel

24 บิตหลัง (3 ไบต์) Device Identifier (NIC Serial)

หมายเลขซีเรียลเฉพาะของแผงวงจรแต่ละใบ

2.2

อุปกรณ์รวมสัญญาณ: ฮับ (Hub) vs สวิตช์ (Switch) vs Layer 3 Switch

1. Hub (ฮับ - เทคโนโลยีเดิม)

Physical Layer (Layer 1)

ส่งข้อมูลแบบ Broadcast (กระจายสัญญาณออกทุกพอร์ต) ไม่มีความฉลาด ทุกอุปกรณ์แชร์ Collision Domain เดียวกัน ทำให้ข้อมูลชนกันบ่อย ความเร็วลดลงอย่างรวดเร็ว ทำงานแบบ Half-Duplex

⚠️ ปัจจุบันยกเลิกการใช้งานแล้ว ถูกแทนที่ด้วย Switch ทั้งหมด

2. Layer 2 Switch (สวิตช์มาตรฐาน)

Data Link Layer (Layer 2)

ส่งข้อมูลแบบ Unicast (เจาะจงเฉพาะพอร์ตปลายทาง) โดยเรียนรู้และสร้าง MAC Address Table แยก Collision Domain ทุกพอร์ต ทำงานแบบ Full-Duplex ข้อมูลไม่ชนกัน

✅ มาตรฐานหลักในระบบแลน (1Gbps, 2.5Gbps, 10Gbps)

3. Managed & Layer 3 Switch

Layer 2 + Layer 3 (IP Routing)

สวิตช์ระดับองค์กรที่สามารถตั้งค่าแบ่งวงเสมือน VLAN (Virtual LAN), รองรับการจ่ายไฟผ่านสายแลน PoE (Power over Ethernet) และทำการ Routing ข้าม VLAN ได้ด้วยความเร็วฮาร์ดแวร์ (ASIC)

⚡ นิยมใช้เป็น Core Switch / Distribution Switch ในองค์กร

สรุปข้อแตกต่างเรื่อง Collision Domain และ Broadcast Domain:

Collision Domain (ขอบเขตการชนกันของข้อมูล): Hub มี 1 Collision Domain รวมกันทั้งเครื่อง | Switch แยก 1 Collision Domain ต่อ 1 พอร์ต (ไม่ชนกัน)
Broadcast Domain (ขอบเขตการกระจายสัญญาณ): Switch ทุกพอร์ตอยู่ใน Broadcast Domain เดียวกัน (ยกเว้นแบ่ง VLAN) | Router ทำหน้าที่ตัดและแยก Broadcast Domain
2.3

เราเตอร์ (Router), เกตเวย์ (Gateway) และโมเด็มไฟเบอร์ (Fiber ONT)

เราเตอร์ (Router) เป็นอุปกรณ์ที่ทำงานในระดับ Network Layer (Layer 3) ทำหน้าที่เชื่อมโยงเครือข่ายคนละวง (ต่าง Subnet) หรือเชื่อมต่อ LAN ภายในบ้าน/องค์กร เข้ากับเครือข่าย WAN ภายนอก (Internet) โดยอ่านหมายเลข IP Address ปลายทาง และเปิดดูตาราง Routing Table เพื่อค้นหาเส้นทางที่เร็วที่สุด (Best Path)

ฟังก์ชันสำคัญของเราเตอร์ในปัจจุบัน:

  • NAT (Network Address Translation): แปลง Private IP หลายเครื่องในบ้านให้ใช้ Public IP เดียวกันออกอินเทอร์เน็ต
  • DHCP Server: จ่ายหมายเลข IP Address, Subnet Mask และ Gateway ให้ลูกข่ายอัตโนมัติ
  • Default Gateway: ประตูทางออกหลักของแพ็กเกจข้อมูลเมื่อต้องการส่งออกนอกเครือข่ายท้องถิ่น
  • QoS (Quality of Service): จัดลำดับความสำคัญของแบนด์วิดท์ เช่น ให้ความสำคัญกับเสียง Voice/Video ก่อนดาวน์โหลดไฟล์

Fiber ONT / ONU (Modem)

Optical Network Terminal

ทำหน้าที่แปลงสัญญาณแสง (Light Pulse) ผ่านสายใยแก้วนำแสง (Fiber Optic GPON) จาก ISP ให้กลายเป็นสัญญาณไฟฟ้าดิจิทัล (Ethernet) ก่อนส่งต่อให้เราเตอร์

เกตเวย์ (Gateway)

Protocol Translator

ด่านเชื่อมต่อและแปลงรูปแบบโพรโทคอลระหว่าง 2 เครือข่ายที่ใช้สถาปัตยกรรมต่างกันอย่างสิ้นเชิง เช่น เชื่อมโยงเครือข่ายองค์กรเข้ากับระบบเมนเฟรม หรือ IoT Gateway

2.4

อุปกรณ์เชื่อมต่อไร้สาย (Access Point) และมาตรฐาน Wi-Fi

Access Point (AP)

สะพานเชื่อมสัญญาณมีสายสู่ไร้สาย

เปลี่ยนสัญญาณ Ethernet จากสายแลน ให้กลายเป็นคลื่นวิทยุเพื่อให้อุปกรณ์เคลื่อนที่สามารถเชื่อมต่อเครือข่ายได้ ในองค์กรจะใช้ Controller ควบคุมหลาย AP พร้อมกัน (Centralized AP) หรือทำระบบ Mesh Wi-Fi (Seamless Roaming) เพื่อให้เดินใช้งานได้ทั่วอาคารโดยสัญญาณไม่หลุด

ย่านความถี่คลื่นวิทยุ Wi-Fi (Frequency Bands):

2.4 GHz
ระยะไกล ทะลุสิ่งกีดขวางดี

ความเร็วปานกลาง (~300-600 Mbps) มีสัญญาณรบกวนมาก เหมาะกับอุปกรณ์ IoT และสมาร์ตโฮม

5.0 GHz
ความเร็วสูง แบนด์วิดท์กว้าง

ความเร็วสูงมาก (~1.3 - 4.8 Gbps) สัญญาณรบกวนน้อย แต่ทะลุกำแพงหนาได้น้อยกว่า

6.0 GHz (Wi-Fi 6E/7)
ช่องสัญญาณใหม่ ไร้การรบกวน

ความเร็วทะลุ 10-40 Gbps Latency ต่ำพิเศษ เหมาะสำหรับ AR/VR, 8K Video และ Gaming

มาตรฐาน IEEE ชื่อทางการตลาด ย่านความถี่ ความเร็วสูงสุดตามทฤษฎี
802.11ac Wi-Fi 5 5 GHz สูงสุด 3.5 Gbps
802.11ax Wi-Fi 6 / 6E 2.4 / 5 / 6 GHz สูงสุด 9.6 Gbps (OFDMA, MU-MIMO)
802.11be Wi-Fi 7 (ล่าสุด) 2.4 / 5 / 6 GHz สูงสุด 46 Gbps (320MHz, 4K-QAM, MLO)
2.5

อุปกรณ์ความปลอดภัยและโครงสร้างพื้นฐานห้องเซิร์ฟเวอร์

1. Hardware Firewall (NGFW)

Next-Generation Firewall

อุปกรณ์ความปลอดภัยเฉพาะทางที่คั่นกลางระหว่างเครือข่ายภายในกับภายนอก ทำหน้าที่ตรวจสอบแพ็กเกจข้อมูลแบบละเอียด (Deep Packet Inspection), กรองมัลแวร์, ป้องกันการโจมตี IPS/IDS และทำ VPN Server

2. Patch Panel & Server Rack

ตู้แร็คมาตรฐาน 19 นิ้วและแผงพักสาย

แผงกระจายสายแลน (Patch Panel) ทำหน้าที่รวมสายแลนถาวรจากทุกห้องเข้ามายังตู้แร็ค (Server Rack) เพื่อให้การเชื่อมต่อเข้ากับสวิตช์ด้วยสาย Patch Cord เป็นระเบียบ ซ่อมบำรุงและตรวจเช็คสัญญาณได้ง่าย

3. UPS (เครื่องสำรองไฟฟ้า)

Uninterruptible Power Supply

จ่ายกระแสไฟฟ้าสำรองเมื่อไฟดับหรือไฟตก ป้องกันอุปกรณ์เน็ตเวิร์กและเซิร์ฟเวอร์ดับกะทันหัน ซึ่งอาจทำให้ข้อมูลเสียหาย พร้อมระบบปรับแรงดันไฟฟ้าอัตโนมัติ (AVR) ยืดอายุการใช้งานฮาร์ดแวร์

2.6

ตารางสรุปเปรียบเทียบอุปกรณ์เครือข่ายตามระดับชั้น OSI (Hardware Summary Matrix)

ชื่ออุปกรณ์ OSI Layer หน่วยข้อมูล (PDU) การระบุตำแหน่ง (Addressing) หน้าที่หลัก
Repeater / Hub Layer 1 (Physical) Bits (0, 1) ไม่มี (กระจายทุกพอร์ต) ขยายสัญญาณไฟฟ้าและรวมสาย
Bridge / Switch Layer 2 (Data Link) Frames MAC Address (48 บิต) สลับส่งข้อมูลตรงตาม MAC Address ปลายทาง
Router / L3 Switch Layer 3 (Network) Packets IP Address (IPv4 / IPv6) ค้นหาเส้นทางข้ามเครือข่าย, NAT, DHCP, กรองทราฟฟิก
Gateway / NGFW Layer 4 - Layer 7 Segments / Data IP + Port Number + Application แปลงโพรโทคอล, ตรวจสอบความปลอดภัยเชิงลึก (DPI)

สรุปประเด็นสำคัญประจำหน่วยที่ 2 (Key Takeaways)

ทบทวนสาระสำคัญเกี่ยวกับฮาร์ดแวร์เครือข่าย

NIC & MAC Address: การ์ดแลนมี MAC Address ขนาด 48 บิต ไม่ซ้ำกันในโลก โดย 24 บิตแรกคือ OUI (ผู้ผลิต) และ 24 บิตหลังคือรหัสอุปกรณ์
Switch vs Hub: Switch แยก Collision Domain ทุกพอร์ตและส่งข้อมูลเฉพาะเจาะจงผ่าน MAC Table ส่วน Hub เป็น Broadcast ทำให้ข้อมูลชนกันบ่อย
Router (Layer 3): ทำหน้าที่เชื่อมต่อเครือข่ายต่างวง หาเส้นทางส่งแพ็กเกจด้วย IP Address และทำหน้าที่ NAT แปลง IP ออกเน็ต
Fiber ONT: แปลงสัญญาณแสงเลเซอร์จากสายไฟเบอร์ออปติก GPON ให้เป็นสัญญาณดิจิทัลเพื่อส่งเข้า Router
Wi-Fi Standards: Wi-Fi 6 (802.11ax) และ Wi-Fi 7 (802.11be) รองรับคลื่น 2.4/5/6 GHz แบนด์วิดท์กว้างพิเศษและความหน่วงต่ำ
Infrastructure: Patch Panel ช่วยจัดระเบียบสายแลนในตู้ Server Rack 19" และ UPS ป้องกันระบบดับเมื่อไฟฟ้ามีปัญหา
